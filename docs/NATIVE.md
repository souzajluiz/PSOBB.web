# Native app (iOS and Android)

The classic client (`client/`) runs inside a native app built with
[Capacitor](https://capacitorjs.com). The app is the same web code in a native
WebView. The game data and the relay (`/bridge`) stay on the PSOBB.web server
(`docs/DEPLOY.md`), so the server must be reachable over **https** from the
phone.

## What the app needs from the server

- **https**: the app's pages come from the app itself, so the server is always
  an address on another origin. The server allows any origin to read its public
  files (`/keys/`, `/psobb-data/`, `/newserv-*`), which hold no credentials.
- **The relay**: the app connects to `wss://<server>/bridge`. Dokploy's proxy
  passes WebSocket upgrades through, as in the web build.
- **The data**: the app cannot open a folder of the player's machine, so the
  game data must be mounted on the server (`/data/psobb-client`) or downloaded
  at start (`PSOBB_DATA_URL`). See `docs/DEPLOY.md`. Only serve data you have
  the right to serve (`docs/LEGAL.md`).

## Build

The server address is compiled into the app: `VITE_SERVER_ORIGIN` (https, no
trailing slash).

```bash
cd client
npm ci
VITE_SERVER_ORIGIN=https://psobb.example.com npm run app:sync   # build + cap sync
npm run app:android   # opens Android Studio
npm run app:ios       # opens Xcode (macOS only)
```

`npm run build:app` builds only the classic client into `dist/`, with its
start page copied to `index.html` (`client/scripts/app-build.mjs`).

The native projects are `client/android` and `client/ios`, generated by
`npx cap add`. Keep them in the repository; `dist/` is generated.

## Builds in CI

`.github/workflows/native-app.yml` (run by hand from the Actions tab, with the
server address as input) builds:

- `psobb-android-debug`: a debug APK, on Ubuntu with the Android SDK.
- `psobb-ios-simulator`: an app for the iOS simulator, on macOS, without
  signing.

Neither is signed for a store or for a real iPhone. For that, see below.

## Store builds

- **Android**: create a release signing key in Android Studio (Build > Generate
  Signed Bundle / APK) and upload the `.aab` to Google Play.
- **iOS**: needs a Mac with Xcode and an Apple Developer account. Open
  `client/ios/App/App.xcodeproj`, set the team and bundle id, and archive. The
  CI does not sign anything.

## Known limits

- **Fullscreen**: the app hides the status bar (`@capacitor/status-bar`). On
  Android the navigation bar stays; the game does not hide it.
- **Pinch zoom**: disabled in the page (`ui/nozoom.ts`, `touch-action`), also in
  the WebView.
- **Folder picker**: not available in the app. Without server data the app shows
  the folder screen and cannot load the game.
- **Orientation**: not locked in the app. The web build locks landscape on
  Android Chrome in fullscreen only.
- **Icons and name**: the default Capacitor icon and the name `PSOBB`. Replace
  the icons in `client/android/app/src/main/res` and
  `client/ios/App/App/Assets.xcassets`.
- **App id**: `app.psobbweb.client` (`client/capacitor.config.ts`). Change it
  before publishing if you want another.
